# 📊 Superstore Sales Analysis Dashboard

## 📌 Project Overview

This project analyzes Superstore sales data using Microsoft Power BI to understand sales performance, profitability, customer behavior, product performance, and regional trends.

The dashboard provides interactive visualizations and KPIs that help identify important business trends and opportunities.

---

## 🎯 Project Objectives

* Analyze overall sales and profit performance
* Identify the best-performing product categories and sub-categories
* Analyze sales and profit by region and state
* Understand customer and segment performance
* Identify monthly and yearly sales trends
* Analyze shipping performance
* Identify products contributing to high sales and profit
* Find areas with low or negative profitability

---

## 🛠️ Tools & Technologies

* **Power BI** – Data cleaning, data modeling, DAX and dashboard development
* **Power Query** – Data transformation and preparation
* **DAX** – Calculated measures and KPIs
* **Microsoft Excel / CSV** – Dataset
* **GitHub** – Project version control and portfolio
